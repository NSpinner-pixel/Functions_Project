# Functions_Project

This project was for practicing JavaScript basics like variables, functions, and if/else logic

It includes 4 tasks:
1. Format full name with proper capitalization
2. Calculate total cost including tax
3. Check if someone is eligible for a program based on age and if they have a job
4. Same as task 2 but with a discount added

Everything is tested using console.log() in the browser

To see it:
Open index.html in the browser
Open the dev tools 
Go to the Console tab to see the results
